# PàdelSerra

Base de dades del Club de Pàdel La Serra (projecte fictici) per a gestionar socis, quotes, reserves de pistes, classes i torneigs.
Projecte Integrador individual de bases de dades.

## Estructura

- `docs/`: proposta (`00_proposta.md`) i memòries de cada fita
- `modelatge/`: diagrama E/R i model relacional
- `sql/`: scripts DDL, DML i DCL (MySQL)
- `nosql/`: extensió MongoDB (registre d'accessos)
- `dades/`: dades de prova

## Estat

- v0.1-proposta: proposta de projecte i backlog inicial (Lliurament 1)
